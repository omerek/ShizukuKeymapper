Root gerektirmeden, [Shizuku](https://shizuku.rikka.app/) ile USB/OTG veya Bluetooth klavye ve mouse
girdisini ekrandaki noktalara dokunuş olarak aktaran Android keymapper.

- Mimari ve yol haritası: [docs/MIMARI.md](docs/MIMARI.md)
- Kurulum, derleme ve Shizuku başlatma: [docs/KURULUM.md](docs/KURULUM.md)

```powershell
.\gradlew.bat assembleDebug
```
